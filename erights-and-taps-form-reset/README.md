# Steps to fix an ERights form issue detected in TAPS

1. Reset the authors form in the ERights system. Tell them to re-fill it putting special care in all the author's fields. See [template](1-author-reset.txt).
2. Once that is done, ask TAPS support to re-pull this data. In MODELS'26 this was not done automatically, we hope it gets fixed for future events. See [template](2-taps-repull-erights).
3. When TAPS support notifies you the information has been re-pulled, double-check it in the TAPS interface.
4. If everything seems fine, inform the authors to continue with the approval steps.
